# Cordis-Wasm (Wasmtime Host)

`cordis-wasm` is the Wasmtime Component Model integration. It compiles, validates, and hosts
WebAssembly components that implement the Cordis kernel world, enforcing per-plugin resource and
execution budgets, capability policy, and a versioned two-layer ABI. A plugin is a Wasmtime
*Component*; the guest reaches the host only through the `cordis:kernel@0.1.0` WIT interface.

Two layers of ABI:

- **Kernel WIT** is fixed and versioned; it describes only lifecycle, registration, call, event, and
  error plumbing.
- **Business service protocol** is generated by `#[cordis::service]` and carried as MessagePack over
  the kernel's `call-service`; the ABI hash prevents same-named incompatible services from satisfying
  each other.

## `WasmEngine`

```rust
#[derive(Clone, Debug)]
pub struct WasmEngine { /* engine: Engine */ }

impl WasmEngine {
    pub fn new() -> Result<Self, WasmHostError>;
    pub const fn engine(&self) -> &Engine;
    pub fn compile(&self, bytes: impl AsRef<[u8]>) -> Result<Component, WasmHostError>;
    pub fn new_store<T>(&self, host: T, limits: &WasmLimits) -> Result<Store<StoreState<T>>, WasmHostError>;
    pub fn prepare_call<T>(&self, store: &mut Store<StoreState<T>>) -> Result<(), WasmHostError>;
}
```

Component compiler configuration shared by all plugin stores. `new` builds an async Component Model
engine with fuel and epoch interruption enabled and **no ambient WASI capabilities** (capabilities
come from `ArtifactPolicy.wasi`).

- `compile` compiles and validates one component.
- `new_store` creates a limited `Store` with `StoreLimits` from `WasmLimits` and performs a
  `prepare_call`.
- `prepare_call` rearms fuel and the epoch deadline immediately before a guest call: sets fuel,
  sets the epoch deadline, and enables the deadline trap.

**Errors** — all three return `WasmHostError::Engine` when Wasmtime rejects the configuration/bytes,
or on fuel configuration failure.

## `WasmLimits`

```rust
#[derive(Clone, Debug, Eq, PartialEq)]
pub struct WasmLimits {
    pub fuel_per_call: u64,
    pub epoch_deadline_ticks: u64,
    pub max_memory_bytes: usize,
    pub max_table_elements: usize,
    pub max_instances: usize,
    pub max_tables: usize,
    pub max_memories: usize,
    pub max_registrations: usize,
    pub max_payload_bytes: usize,
}
```

Per-plugin resource and execution budgets. `Default` grants: `fuel_per_call: 10_000_000`,
`epoch_deadline_ticks: 1`, `max_memory_bytes: 64 MiB`, `max_table_elements: 10_000`,
`max_instances/tables/memories: 32`, `max_registrations: 10_000`, `max_payload_bytes: 1 MiB`.

## `StoreState<T>`

```rust
#[derive(Debug)]
pub struct StoreState<T> { /* host: T, limiter: StoreLimits, fuel_per_call, epoch_deadline_ticks, active_registrations, max_registrations */ }

impl<T> StoreState<T> {
    pub const fn host(&self) -> &T;
    pub const fn host_mut(&mut self) -> &mut T;
    pub const fn active_registrations(&self) -> usize;
    pub fn reserve_registration(&mut self) -> Result<(), WasmHostError>;
    pub fn release_registration(&mut self) -> Result<(), WasmHostError>;
}
```

Store-owned host state and enforceable budgets. The registration counter track host-authored
registrations (provider/listener) so the host can enforce `max_registrations` even if the guest never
drops its handles.

**Errors** — `reserve_registration` returns `WasmHostError::RegistrationLimitExceeded { limit }` at the
configured limit; `release_registration` returns `WasmHostError::RegistrationCountUnderflow` for an
unmatched release.

## `ArtifactPolicy`

```rust
#[derive(Clone, Debug)]
pub struct ArtifactPolicy {
    pub kernel_abi: String,
    pub allowed_capabilities: BTreeSet<Capability>,
    pub wasi: WasiCapabilities,
}
impl Default for ArtifactPolicy {
    /* kernel_abi: "0.1", allowed_capabilities: empty, wasi: WasiCapabilities::deny_all() */
}
```

Descriptor and capability checks performed before a component becomes a candidate. The default
denies everything: an empty capability set and no WASI preopens.

## `WasmComponentFactory`

```rust
#[derive(Clone, Debug)]
pub struct WasmComponentFactory { /* engine, component: Arc<Component>, descriptor, limits, policy */ }

impl WasmComponentFactory {
    pub async fn from_bytes(
        engine: WasmEngine, bytes: impl AsRef<[u8]>, limits: WasmLimits, policy: ArtifactPolicy,
    ) -> Result<Self, WasmHostError>;
    pub fn component(&self) -> &Component;
    pub const fn policy(&self) -> &ArtifactPolicy;
}
impl ComponentFactory for WasmComponentFactory { /* descriptor(), instantiate(&host) */ }
```

A validated, compiled WebAssembly component implementing the Cordis kernel world. `from_bytes`
compiles, links, instantiates, and **queries the descriptor** without activating the guest — so the
host learns the component's name, injects, provides, config schema, and capabilities before any code
runs. It then validates the descriptor (kernel ABI, capabilities) and the WASI imports against the
policy.

**Errors** — `from_bytes` returns compilation, linking, descriptor, ABI, or capability policy errors.

## `WasiCapabilities` / `WasiPreopen`

```rust
#[derive(Clone, Debug, Eq, PartialEq)]
pub struct WasiPreopen {
    pub host_path: PathBuf,
    pub guest_path: String,
    pub writable: bool,
}
impl WasiPreopen {
    pub fn read_only(host_path: impl Into<PathBuf>, guest_path: impl Into<String>) -> Self;
    pub fn read_write(host_path: impl Into<PathBuf>, guest_path: impl Into<String>) -> Self;
}

#[derive(Clone, Debug, Default, Eq, PartialEq)]
pub struct WasiCapabilities { /* preopens: Vec<WasiPreopen> */ }
impl WasiCapabilities {
    pub fn deny_all() -> Self;
    #[must_use] pub fn with_preopen(mut self, preopen: WasiPreopen) -> Self;
    pub fn preopens(&self) -> &[WasiPreopen];
}
```

`WASIp2` policy. Its default (`deny_all`) grants no ambient process, filesystem, or network access;
you opt in per preopen. `with_preopen` adds one. A guest preopen path must be **relative and not
contain `..`** — `build` rejects absolute paths and `ParentDir` components, so a preopen cannot
escape the guest's virtual tree.

## `GuestTaskGroup`

```rust
#[derive(Debug, Default)]
pub struct GuestTaskGroup { /* tasks: Vec<JoinHandle<()>> */ }

impl GuestTaskGroup {
    pub fn spawn(&mut self, task: impl Future<Output = ()> + Send + 'static);
    pub fn len(&self) -> usize;
    pub fn is_empty(&self) -> bool;
    pub async fn shutdown(&mut self);
}
```

Host-owned tasks bounded to one instance. **Host-owned tasks are always aborted and joined before a
Store is discarded** — `shutdown` aborts every task and awaits each handle, so a task that leaks a
reference into the Store cannot outlive it.

## The `cordis:kernel@0.1.0` WIT world

The canonical source is `crates/cordis-guest/wit/kernel.wit`; `cordis-wasm` packages an identical copy
under `crates/cordis-wasm/wit/kernel.wit` and a test asserts they match byte-for-byte.

The world `cordis-plugin` has two interfaces:

### `host` (imported by the plugin)

| Function | Signature |
|---|---|
| `log` | `(context: call-context, level: string, message: string)` |
| `call-service` | `(context, service: service-id, method: u32, payload: list<u8>) -> result<list<u8>, kernel-error>` |
| `provide-service` | `(context, service: service-id) -> result<registration, kernel-error>` |
| `register-listener` | `(context, event: event-id, listener-id: u64, mode: event-mode) -> result<registration, kernel-error>` |
| `dispatch-event` | `(context, event: event-id, listener-id: u64, mode: event-mode, payload: list<u8>, next-token: option<u64>) -> result<event-reply, kernel-error>` |

`call-context` is `{ fiber-id: u64, effect-id: u64 }`; the host validates it against the current
Store before every call (`InvalidArgument` if it does not belong to the Store). `event-mode` is the
five-variant enum. `event-reply` is `continue-value`/`break-value`, each a `list<u8>`. `registration`
is a `resource` — its destructor (`drop`) is what releases a host-side registration.

### `plugin` (exported by the plugin)

| Function | Signature |
|---|---|
| `descriptor` | `() -> plugin-descriptor` |
| `activate` | `(context, config: list<u8>) -> result<_, kernel-error>` |
| `deactivate` | `(context) -> result<_, kernel-error>` |
| `call-service` | `(context, service, method, payload) -> result<list<u8>, kernel-error>` |
| `handle-event` | `(context, event, listener-id, mode, payload, next-token) -> result<event-reply, kernel-error>` |

`plugin-descriptor` declares `name`, `version`, `wit-version` (the kernel ABI), `inject`/`provide`
as `list<service-id>`, `config-schema` as `list<u8>` (JSON bytes), and `capabilities` as
`list<string>`.

## `WasmHostError`

```rust
#[derive(Debug, thiserror::Error)]
pub enum WasmHostError {
    #[error("wasmtime component error: {0}")] Engine(#[from] wasmtime::Error),
    #[error("guest registration limit {limit} exceeded")] RegistrationLimitExceeded { limit: usize },
    #[error("guest registration count underflow")] RegistrationCountUnderflow,
    #[error("invalid component descriptor: {message}")] Descriptor { message: String },
    #[error("kernel ABI mismatch: expected {expected}, got {actual}")] KernelAbiMismatch { expected: String, actual: String },
    #[error("component capability `{capability}` is denied")] CapabilityDenied { capability: String },
    #[error("invalid WASI capability: {message}")] Capability { message: String },
}
```

The host-side error enum. `Engine` wraps any Wasmtime error.

## Kernel-bindings note

The two `bindings` modules (`bindings::cordis::kernel::host`, `bindings::exports::cordis::kernel::plugin`)
are generated at build time by `wit_bindgen` (host) and `wit-bindgen::generate!` (guest). They expose
the WIT types as Rust — e.g. `host::KernelError`, `host::EventMode`, `plugin::Guest`, `plugin::PluginDescriptor`.
