# Service

The service subsystem is Cordis's RPC boundary. A **service** is a named, typed surface declared as a
trait by `#[cordis::service]`. Native and WebAssembly components share the same `ServiceId`, the same
`ServiceDispatcher` transport, and the same `MessagePack` payload codec — which is how a native
provider can serve a Wasm consumer and vice versa. Services are also the unit of **reactive
dependency injection**: a component declares which services it wants, and it activates only once
they are all provided.

## `ServiceId`

```rust
#[derive(Clone, Debug, Eq, Hash, Ord, PartialEq, PartialOrd)]
pub struct ServiceId { /* name: Arc<str>, abi_hash: [u8; 32] */ }

impl ServiceId {
    pub fn new(name: impl Into<Arc<str>>, abi_hash: [u8; 32]) -> Self;
    pub fn of<K: ServiceKey>() -> Self;
    pub fn name(&self) -> &str;
    pub const fn abi_hash(&self) -> &[u8; 32];
}
```

Stable service identity shared by every component kind. A `ServiceId` is a **name** plus a **32-byte
ABI hash**. Two services with the same name but different signatures get different hashes, so they
do not satisfy each other — this is the paper's key-namespacing route (§6.6).

`Display` is `{name}@{first-4-bytes-of-hash-as-hex}` (e.g. `test.service@abababab`), matching the
test `typed_identity_contains_name_and_abi_hash`.

## `ServiceKey`

```rust
pub trait ServiceKey: Send + Sync + 'static {
    const NAME: &'static str;
    const ABI_HASH: [u8; 32];
}
```

Compile-time service identity generated by `#[cordis::service]`. The marker type (e.g.
`CounterService`) implements this; it is the zero-sized token you hand to `ServiceSpec::service_id`
and to `ServiceClient::new`.

## `ServiceSpec`

```rust
pub trait ServiceSpec: ServiceKey {
    fn service_id() -> ServiceId
    where
        Self: Sized,
    {
        ServiceId::of::<Self>()
    }
}
impl<T: ServiceKey> ServiceSpec for T {}
```

Blanket-implemented for every `ServiceKey`: gives them a `service_id()` as a convenience. The macro's
generated marker implements it.

## `ServiceDispatcher`

```rust
pub trait ServiceDispatcher: Send + Sync + 'static {
    fn service_id(&self) -> ServiceId;
    fn dispatch(&self, method_id: u32, payload: Vec<u8>) -> ServiceFuture;
}
```

The **object-safe transport boundary**. This is what the macro's `CounterDispatcher<T>` and the Wasm
runtime both implement, so native and dynamic clients are interchangeable from the caller's point of
view. `service_id` declares which service this dispatcher provides; `dispatch` routes one
already-encoded method call. Whatever `dispatch` returns is the *wire* response — a codec call
(`decode_service_payload`) on the caller's side turns it into a typed result.

## `ServiceClient`

```rust
#[derive(Clone)]
pub struct ServiceClient { /* service: ServiceId, dispatcher: Arc<dyn ServiceDispatcher> */ }

impl ServiceClient {
    pub fn new<S: ServiceSpec>(dispatcher: Arc<dyn ServiceDispatcher>) -> Result<Self, CordisError>;
    pub fn service_id(&self) -> &ServiceId;
    pub async fn call(&self, method_id: u32, payload: Vec<u8>) -> Result<Vec<u8>, CordisError>;
}
```

Checked, type-erased transport used internally by generated clients. `new` verifies the dispatcher's
`ServiceId` (name and ABI hash) against the expected spec before returning.

**Errors** — `new` returns `CordisError::ServiceIdentityMismatch { expected, actual }` when the
dispatcher does not implement the requested service ABI. `call` returns the transport or provider
error reported by the dispatcher.

## `ServiceFuture`

```rust
pub type ServiceFuture =
    Pin<Box<dyn Future<Output = Result<Vec<u8>, CordisError>> + Send + 'static>>;
```

Owned future returned by a native or WebAssembly service dispatcher.

## `ServiceCallError<E>`

```rust
#[derive(Clone, Debug, Eq, PartialEq)]
pub enum ServiceCallError<E> {
    Transport(CordisError),
    Service(E),
}
impl<E> From<CordisError> for ServiceCallError<E> { ... }
```

The error type returned by every generated client method. It separates the **transport** (codec,
routing, ABI mismatch — anything in the Cordis machinery) from the **service's own declared error**
`E`. `From<CordisError>` turns a transport failure into `ServiceCallError::Transport`, so `?` inside
a client-builder propagates the transport half. Implements `Display` and `std::error::Error` (with
`source` returning the inner error).

## `ProviderKey`

```rust
#[derive(Clone, Debug, Eq, Hash, Ord, PartialEq, PartialOrd)]
pub struct ProviderKey {
    pub service: ServiceId,
    pub realm: RealmId,
}
impl ProviderKey {
    pub const fn new(service: ServiceId, realm: RealmId) -> Self;
}
```

The unique slot a service provider occupies. At most one fiber may provide a given
`(service, realm)` pair. Uniquely identifying a provider by **service + realm** is the paper's
§6.2 "realms" route to service multiplexing (the other route, exclusive binding, is `set` with its
`DuplicateProvider` precondition).

## `InjectSpec`

```rust
#[derive(Clone, Debug, Eq, PartialEq)]
pub struct InjectSpec {
    pub service: ServiceId,
    pub requirement: Requirement,
}
impl InjectSpec {
    pub const fn required(service: ServiceId) -> Self;
    pub const fn optional(service: ServiceId) -> Self;
}
```

One dependency declared by a component. A `required` dependency keeps the fiber from activating
until a provider appears; an `optional` one does not. `DependencySet::injects` returns these.

## `Requirement`

```rust
#[derive(Clone, Copy, Debug, Eq, PartialEq)]
pub enum Requirement { Required, Optional }
```

Whether a missing provider keeps a fiber inactive.

## `DependencyResolution`, `ResolvedInject`, `CommittedView`

```rust
#[derive(Clone, Debug, Eq, PartialEq)]
pub struct ResolvedInject {
    pub key: ProviderKey,
    pub provider: Option<FiberId>,
    pub requirement: Requirement,
}

#[derive(Clone, Debug, Default, Eq, PartialEq)]
pub struct DependencyResolution { /* entries: Vec<ResolvedInject> */ }
impl DependencyResolution {
    pub fn new(entries: Vec<ResolvedInject>) -> Self;
    pub fn entries(&self) -> &[ResolvedInject];
    pub fn is_ready(&self) -> bool;
    pub fn commit(&self) -> Result<CommittedView, CordisError>;
}

#[derive(Clone, Debug, Default, Eq, PartialEq)]
pub struct CommittedView { /* entries: BTreeMap<ServiceId, ResolvedInject> */ }
impl CommittedView {
    pub fn lookup(&self, service: &ServiceId) -> Result<Option<FiberId>, CordisError>;
    pub fn entries(&self) -> impl ExactSizeIterator<Item = &ResolvedInject>;
}
```

- `DependencyResolution` is the current resolution of a fiber's declared dependencies in its
  context. `is_ready()` is `σ ⊨ d` (satisfaction, Definition 21): every entry has a provider or is
  optional.
- `commit()` **freezes** the ready resolution into a `CommittedView` — the `ω_n` the fiber will
  actually run against. It is immutable for the load epoch.
- `CommittedView::lookup` returns the provider (`Option<FiberId>`), or `Err(UndeclaredDependency)`
  if the service was never declared by this fiber (the capability check of §6.3: a component can only
  access what it declared).

**Errors** — `commit` returns `CordisError::InactiveDependency { key }` if a required provider is
absent. `lookup` returns `CordisError::UndeclaredDependency { service }` for an unknown service.

## `ProviderKey` consuming vs `RegistryChange`

`RegistryChange` lives in [supervisor](supervisor.md); it is the result of provide/withdraw.

## Payload codec

```rust
pub fn encode_service_payload<T: Serialize>(value: &T) -> Result<Vec<u8>, CordisError>;
pub fn decode_service_payload<T: DeserializeOwned>(payload: &[u8]) -> Result<T, CordisError>;
```

Encodes / decodes one service payload using the canonical `MessagePack` codec. Native and Wasm
dispatch both use these, which is why the business service protocol is MessagePack over the Kernel
WIT rather than TS objects (README: "does not promise binary compatibility with TS plugins").

**Errors** — `encode` returns `CordisError::ServiceEncodeFailed { message }`; `decode` returns
`CordisError::ServiceDecodeFailed { message }`.

## Example

```rust
let dispatcher = Arc::new(CounterDispatcher::new(Arc::new(AtomicCounter::default())));
let client = CounterClient::new(dispatcher)?;   // checks name + ABI hash
let value = client.add(3).await.map_err(|e| match e {
    ServiceCallError::Transport(e) => e,
    ServiceCallError::Service(msg) => /* the provider's String */ ...,
})?;
```

Or, with no serialization at all, `CounterClient::from_native(arc)` calls straight through a
macro-generated object-safe adapter.
