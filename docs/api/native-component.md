# Native Components

The native authoring path lets you write a component as ordinary Rust, statically linked, with zero
serialization on the direct path. The `#[cordis::component]` / `#[cordis::component_impl]` pair
generates the `Component` implementation, the dependency set, and the descriptor that the supervisor
uses to mount and drive the component. This page documents the traits and types the macros consume
and the runtime types you interact with; see [macros](macros.md) for the macro contract itself.

## `ComponentDefinition`

```rust
pub trait ComponentDefinition: Send + 'static {
    type Config: DeserializeOwned + JsonSchema + Send + Sync + 'static;
    type Deps: DependencySet;

    fn descriptor() -> &'static ComponentDescriptor;
}
```

Metadata and associated types shared by the generated component adapter. `type Config` is the typed
config (`DeserializeOwned + JsonSchema`); `type Deps` is the generated dependency set;
`descriptor()` returns the cached descriptor.

## `ComponentDescriptor`

```rust
#[derive(Clone, Debug)]
pub struct ComponentDescriptor {
    pub name: &'static str,
    pub injects: Vec<InjectSpec>,
    pub config_schema: fn() -> Schema,
}
```

Immutable metadata generated by `#[cordis::component]`. `name` is the component name; `injects` are
the declared dependencies; `config_schema` is a function returning the Draft 2020-12 JSON Schema.

## `Component`

```rust
pub trait Component: ComponentDefinition {
    fn apply(
        self,
        context: ComponentContext<Self::Deps>,
        config: Self::Config,
    ) -> impl Future<Output = Result<ComponentEffects, CordisError>> + Send;
}
```

The executable component. Implemented by the `#[cordis::component_impl]` expansion. `apply` is the
effect body: given the component's context (dependency clients, fiber context, the effect set) and
its typed config, it registers effects and returns a `ComponentEffects` that hands the retained
`EffectSet` back to the fiber. On error it disposes the effects and returns the error.

## `ComponentContext<D>`

```rust
#[derive(Clone, Debug)]
pub struct ComponentContext<D: DependencySet> { /* context, deps: Arc<D>, effects, method_runtime */ }

impl<D: DependencySet> ComponentContext<D> {
    pub fn new(context: Context, deps: D, effects: EffectSet) -> Self;
    #[must_use] pub fn with_method_runtime(mut self, runtime: MethodFiberRuntime) -> Self;
    pub fn context(&self) -> &Context;
    pub fn deps(&self) -> &D;
    pub fn effects(&self) -> &EffectSet;
    pub fn effect_set(&self) -> EffectSet;
    pub async fn register_method<D2, F, Fut>(
        &self, label: &'static str, callback: F,
    ) -> Result<FiberId, CordisError>
    where
        D2: DependencySet,
        F: Fn(MethodContext<D2>) -> Fut + Send + Sync + 'static,
        Fut: Future<Output = Result<(), CordisError>> + Send + 'static;
}
```

Context handed to a native component's `apply` method. `deps()` gives the typed dependency clients
(e.g. `context.deps().counter`); `effect_set()` gives the fiber's `EffectSet` to register effects
under; `context()` gives the `Context` for realm/intercept resolution.

### `with_method_runtime`

Enables method-level inject registration for this component load. Called by the code that mounts the
component when a `MethodFiberRuntime` is available; without it `register_method` returns
`CordisError::MissingMethodRuntime`.

### `register_method`

Registers one generated method as an **effect-owned child fiber**. The method becomes a separate
fiber whose context extends this component's context, with its own `DependencySet` resolved from the
committed view; it is installed as an executor on the supervisor via the provided `MethodFiberRuntime`.
The method's effect set is disposed on unload, and retiring the child fiber is deferred as a disposer
into this component's effect set — so when the component unloads, its method fibers are torn down.

This is how `#[cordis::inject]` on a method inside `#[cordis::component_impl]` works: each such
method is a child fiber with its own dependencies.

**Errors** — returns an error if this context has no method runtime, the parent is inactive,
dependency configuration fails, or the owning effect has begun disposal.

## `ComponentEffects`

```rust
#[derive(Clone, Debug)]
pub struct ComponentEffects { /* effects: EffectSet */ }
impl ComponentEffects {
    pub fn new(effects: EffectSet) -> Self;
    pub fn effect_set(&self) -> &EffectSet;
}
```

Effects retained after a component applies successfully. `apply` returns this; the supervisor stores
it as the fiber's cleanup and disposes it when the fiber unloads (LIFO).

## `DependencySet`

```rust
pub trait DependencySet: Send + Sync + 'static {
    fn injects() -> Vec<InjectSpec>;
    fn resolve(resolver: &dyn DependencyResolver) -> Result<Self, CordisError>
    where
        Self: Sized;
}
```

Compile-time dependency declaration for a native component or injected method. `injects()` returns
the declared `InjectSpec`s; `resolve()` builds the generated typed client set from a committed
dependency view. The generated `CounterConsumerDependencies` implements this.

**Errors** — `resolve` returns an error when a selected provider has no matching dispatcher.

## `NoDependencies`

```rust
#[derive(Clone, Copy, Debug, Default)]
pub struct NoDependencies;
impl DependencySet for NoDependencies { /* injects() -> vec![], resolve() -> Ok(Self) */ }
```

A dependency set for a component with no injects.

## `DependencyResolver`

```rust
pub trait DependencyResolver {
    fn resolve(&self, service: &ServiceId) -> Result<Arc<dyn ServiceDispatcher>, CordisError>;
}
```

Resolves the dispatcher selected by one committed fiber load epoch. Given the service it returns the
`Arc<dyn ServiceDispatcher>` for the provider chosen in the committed view.

**Errors** — returns an error when the committed view has no provider, or the native provider did not
register its dispatcher.

## `MethodContext<D>` and `MethodFiberRuntime`

```rust
#[derive(Clone, Debug)]
pub struct MethodContext<D: DependencySet> { /* context, deps: Arc<D>, effects */ }
impl<D: DependencySet> MethodContext<D> {
    pub fn context(&self) -> &Context;
    pub fn deps(&self) -> &D;
    pub fn effects(&self) -> &EffectSet;
    pub fn effect_set(&self) -> EffectSet;
}

#[derive(Clone, Debug)]
pub struct MethodFiberRuntime { /* runtime: RuntimeHandle, services: NativeServiceRegistry */ }
impl MethodFiberRuntime {
    pub fn new(runtime: RuntimeHandle, services: NativeServiceRegistry) -> Self;
    pub fn services(&self) -> &NativeServiceRegistry;
}
```

- `MethodContext` is the context passed to one method-level injected child fiber. Same accessors as
  `ComponentContext`, minus `register_method`.
- `MethodFiberRuntime` is the runtime bridge used by generated method-level injects: it carries the
  `RuntimeHandle` (to create child fibers, commit dependencies, install executors) and the
  `NativeServiceRegistry` (to resolve native dispatchers).

## `NativeServiceRegistry`

```rust
#[derive(Clone, Default)]
pub struct NativeServiceRegistry { /* dispatchers: Arc<RwLock<BTreeMap<(FiberId, ServiceId), Arc<dyn ServiceDispatcher>>>> */ }
impl NativeServiceRegistry {
    pub fn new() -> Self;
    pub fn insert(&self, provider: FiberId, dispatcher: Arc<dyn ServiceDispatcher>);
    pub fn remove(&self, provider: FiberId, service: &ServiceId);
    pub fn len(&self) -> usize;
    pub fn is_empty(&self) -> bool;
}
```

Native service dispatchers keyed by their provider fiber. A native provider registers its dispatcher
here via `insert`, so a generated dependency client can resolve it by `(provider, service)`.

**Errors** — the internal `resolve` returns `CordisError::MissingServiceDispatcher { provider, service }`
when no dispatcher is registered for that pair.

## `MethodFiberRuntime` + dependency resolution flow

`DependencySet::resolve` is handed a `dyn DependencyResolver`. The generated component adapter uses
the committed view + the native registry:

```rust
struct CommittedDependencyResolver<'a> { committed: &'a CommittedView, services: &'a NativeServiceRegistry }
impl DependencyResolver for CommittedDependencyResolver<'_> {
    fn resolve(&self, service: &ServiceId) -> Result<Arc<dyn ServiceDispatcher>, CordisError> {
        let provider = self.committed.lookup(service)?.ok_or(CordisError::MissingCommittedProvider { service: service.clone() })?;
        self.services.resolve(provider, service)
    }
}
```

## Hidden internals

These are `#[doc(hidden)]` in the source — real public API, but intended for macro-generated code,
not for direct use. A component author never names them.

### `ComponentCell<T>`

```rust
#[doc(hidden)]
pub struct ComponentCell<T> { /* inner: Arc<AsyncMutex<T>> */ }
impl<T> ComponentCell<T> {
    pub fn new(value: T) -> Self;
    pub async fn lock(&self) -> tokio::sync::MutexGuard<'_, T>;
}
```

Shared, asynchronously serialized ownership used by generated component adapters. The `apply` method
locks the component instance behind this cell so method registrations and the `apply` body share a
single `&mut self`-owner without data races.

### `catch_component_future`

```rust
#[doc(hidden)]
pub async fn catch_component_future<T, F>(fiber: FiberId, future: F) -> Result<T, CordisError>
where F: Future<Output = Result<T, CordisError>> + Send;
```

Converts a panic in generated component code into a fiber failure. Wraps the future in
`AssertUnwindSafe(...).catch_unwind()`; a panic becomes `CordisError::FiberExecutorPanicked { fiber, message }`.

## `config_schema`

```rust
pub fn config_schema<T: JsonSchema>() -> Schema
```

Generates a Draft 2020-12 JSON Schema without requiring macros to name schemars internals.
