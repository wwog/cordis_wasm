# Changelog

All notable changes to Cordis are documented here. The project follows Semantic Versioning.

## 0.1.0 - Unreleased

- Added effect-owned lifecycle, Context/realm routing, dependency reconciliation, events, and
  method-level injected child Fibers.
- Added typed native component, service, event, and configuration macros.
- Added Wasmtime Component Model hosting, WASIp2 capability policy, guest SDK, and typed Kernel
  routing.
- Added declarative JSON/YAML loading, transactional reconciliation, artifact and configuration
  hot reload, process-local built-ins, timers, logging, and tracked collections.
- Added the `cordis` check, run, inspect, and build-component commands.
